# SingletonIdGenerator

Консольное приложение на C#, демонстрирующее реализацию паттерна **Singleton** на примере генератора уникальных идентификаторов.

Программа создаёт один общий генератор ID, который:

* выдаёт уникальные числовые значения (`1`, `2`, `3`, …)
* формирует ID с префиксом (`USR-1`, `ORD-2`, …)
* работает корректно в многопоточном режиме

---

## Идея проекта

Главная задача — реализовать единый источник генерации ID в рамках одного процесса.

Если бы можно было создать несколько экземпляров генератора, каждый начал бы считать с `1`, что привело бы к дубликатам.
Паттерн **Singleton** гарантирует существование только одного экземпляра класса.

---

## Реализация Singleton

Singleton реализован в классе `IdGenerator`.

### 1. Единственный экземпляр

```csharp
private static IdGenerator _instance;
```

Статическое поле хранит ссылку на единственный объект.

---

### 2. Закрытый конструктор

```csharp
private IdGenerator() { }
```

Это запрещает создание объекта через `new IdGenerator()` вне класса.

---

### 3. Глобальная точка доступа

```csharp
public static IdGenerator GetInstance()
{
    lock (_lock)
    {
        if (_instance == null)
        {
            _instance = new IdGenerator();
        }
    }

    return _instance;
}
```

Метод `GetInstance()`:

* создаёт объект при первом вызове
* возвращает уже созданный экземпляр при следующих вызовах
* потокобезопасен благодаря `lock`

---

## Потокобезопасность генерации ID

```csharp
public long NextId()
{
    return Interlocked.Increment(ref _counter);
}
```

Используется `Interlocked.Increment`, который:

* атомарно увеличивает счётчик
* исключает дубликаты ID
* безопасен при работе из нескольких потоков

---

## Генерация ID с префиксом

```csharp
public string NextId(string prefix)
{
    return $"{prefix}-{NextId()}";
}
```

Позволяет получать идентификаторы формата:

* `USR-1`
* `ORD-2`
* `ITEM-3`

Все они продолжают одну общую числовую последовательность.

---

## Пример работы программы

В `Main` создаются две переменные:

```csharp
var generator1 = IdGenerator.GetInstance();
var generator2 = IdGenerator.GetInstance();
```

Проверка:

```csharp
Object.ReferenceEquals(generator1, generator2);
```

Результат:

```
True
```

Это доказывает, что обе переменные указывают на один и тот же объект.

Пример вывода программы:

```
Проверка Singleton:
True

Генерация ID:
1
2
USR-3
ORD-4
```
